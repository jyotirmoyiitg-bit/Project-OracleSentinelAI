Oracle Sentinel AI

High-level architecture and the three data paths: scheduled collection, GraphDB, and a copilot question. Open this file in a browser. The API on port 8000 is also the Oracle MCP server. It has no second listen port.

1. High-level architecture

The portal is the only operator surface. The API on port 8000 stays up, owns collection and GraphDB, and is the MCP server for Oracle readings. Oracle is reached with fixed SQL as GSYSTEM. The language model never chooses a reading and is not required for collection or GraphDB.

2. Data flow

Collection stores history. GraphDB shows the current Oracle snapshot and keeps rate samples in the page. A copilot question is answered by the API acting as the Oracle MCP server.

Always on
Scheduled collection. The API scheduler polls each registered alias on its interval. A language model is not involved.
  • Health, tablespace, FRA, alert log, and configuration probes run as GSYSTEM.
  • Rows are stored in PostgreSQL. Rules open incidents. Forecasts use retained samples.
  • Approved files in the knowledge folders are parsed and embedded locally. Collection never reads those files to decide what SQL to run.
On open
GraphDB for one database. An administrator opens #/graph and chooses a registered database. The shell does not connect to Oracle. The page then asks for memory, storage, and activity.
On ask
One database question. Fleet chat does not open Oracle. The question must be asked on a database. This is the path where the API acts as the Oracle MCP server.

3. Implementation

GraphDB and collection call the fixed catalog inside the API process. A copilot question uses that same API as the Oracle MCP server, over stdin and stdout.

4. Proposals and privileged operations

An operator can store and approve a fixed tablespace change. Release 1 does not run it. The privileged path answers 501, writes an audit row, and does not open Oracle.

Boundaries that stay in force

Monitoring stands alone

Collection, GraphDB, rules, and incidents keep running when the model is off and when no question is being asked.

Read-only Oracle

GSYSTEM has SELECT on listed views. The catalog is the only SQL. AWR, ASH, and ADDM are not used.

Evidence stays visible

GraphDB shows the reading or a named limitation. Copilot lists the reading under the narration. A model sentence does not replace the rows.

Execution stays off

Proposals can be approved. Privileged execution returns 501, is audited, and does not open Oracle.
