ORA-15063: ASM discovered an insufficient number of disks for diskgroup string ASM Storage
Description

The ASM instance cannot discover enough valid member disks to assemble and mount the specified disk group.

Possible Causes

ASM_DISKSTRING parameter does not match actual block device paths, or OS device permissions reset after reboot.

Resolution
-- Set broader discovery string
ALTER SYSTEM SET ASM_DISKSTRING = '/dev/oracleasm/disks/*', '/dev/mapper/*' SCOPE=BOTH;

-- Verify OS disk permissions
chown grid:asmadmin /dev/mapper/asm-disk*
chmod 660 /dev/mapper/asm-disk*

-- Mount disk group
ALTER DISKGROUP data MOUNT;
ORA-29701: unable to connect to Cluster Synchronization Service (CSS) RAC / Grid
Description

The database instance cannot initialize in cluster mode because the CSS daemon (ocssd.bin) is inaccessible or stopped.

Possible Causes

Grid Infrastructure stack is stopped, CSS daemon crashed, or cluster IPC communication timed out.

Resolution
# Check Clusterware status
crsctl check crs

# Start cluster stack if down
crsctl start crs

# Inspect CSS daemon trace logs
tail -100f $GRID_HOME/log/$(hostname)/cssd/ocssd.log
ORA-29740: evicted by member string, reason string RAC Eviction
Description

The local RAC node was fenced/evicted from the cluster to prevent data corruption across shared storage.

Possible Causes

Private interconnect network packet drop/latency, voting disk heartbeat timeouts, or severe OS kernel memory paging/hang.

Resolution
-- Validate voting disk availability and heartbeat
crsctl query css votedisk

# Verify Jumbo Frames MTU match across all private interconnect NICs
ip link show | grep mtu

# Review cluster alert log
$GRID_HOME/log/$(hostname)/alert$(hostname).log
ORA-16191: Primary log shipping client not using same password file as standby Data Guard
Description

Redo transport authentication failed because the SYS password file does not match between Primary and Standby databases.

Possible Causes

SYS password was altered on the Primary without updating the Standby password file.

Resolution
# Copy password file from Primary to Standby
scp $ORACLE_HOME/dbs/orapwPRIM standby_host:$ORACLE_HOME/dbs/orapwSTBY

-- On Primary: Restart redo transport
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE_2 = DEFER SCOPE=BOTH;
ALTER SYSTEM SET LOG_ARCHIVE_DEST_STATE_2 = ENABLE SCOPE=BOTH;
ORA-16086: standby database does not contain available standby redo log files Data Guard
Description

Real-time redo transport cannot start because suitable Standby Redo Logs (SRLs) are missing or misconfigured on the standby.

Possible Causes

SRLs were never created on the standby, or their byte size does not match primary Online Redo Logs.

Resolution
-- Match SRL size exactly to primary V$LOG byte size
ALTER DATABASE ADD STANDBY LOGFILE GROUP 10 ('+DATA') SIZE 1073741824;
ALTER DATABASE ADD STANDBY LOGFILE GROUP 11 ('+DATA') SIZE 1073741824;
ALTER DATABASE ADD STANDBY LOGFILE GROUP 12 ('+DATA') SIZE 1073741824;
